# ADR-711-04 — status stocké, phase dérivée

**Date :** 2026-09-06  
**Statut :** accepté  
**Issue :** #711

## Décision

**Stocker** ce qu'un humain décide. **Dériver** ce que les dates impliquent.

- `status` ∈ {brouillon, publiée, annulée, clôturée, archivée, purgée}
- `phase` ∈ {à venir, inscriptions ouvertes, en cours, terminée} — accessor + scopes, **pas** une colonne
- Cinq dates, contrainte d'ordre **en base** : `enrollment_opens_at`, `enrollment_closes_at`, `starts_on`, `ends_on`, `certificate_available_at`
- `cancelled` + `min_enrollments` (alerte sous-inscription)
- « Reportée » n'est **pas** un état : c'est l'opération de rebasage

## Pourquoi

Canvas ne stocke que des décisions humaines. Masteriyo dérive les phases de dates. Mélanger les deux impose un job nocturne qui fera diverger l'étiquette en silence.

## Conséquences

Enums backed string (`app/Enums/`). Contrainte SQL CHECK ou trigger équivalent SQLite/MySQL dans #710. Pas de job « avancer le statut ».
