   INSTALLATION DU SCHEDULER LARAVEL (SOLUTION AUTOMATIQUE)
═══════════════════════════════════════════════════════════════════════

PROBLÈME ACTUEL :
-----------------
Les jobs automatiques ne fonctionnent pas car le scheduler Laravel
n'est pas configuré pour tourner en permanence.

Résultat : Les séances ne se ferment pas automatiquement, les
participants déconnectés ne sont pas détectés, etc.


SOLUTION :
----------
Créer une tâche planifiée Windows qui exécute le scheduler Laravel
AUTOMATIQUEMENT chaque minute.


═══════════════════════════════════════════════════════════════════════
   ÉTAPES D'INSTALLATION (5 MINUTES)
═══════════════════════════════════════════════════════════════════════

ÉTAPE 1 : Ouvrir l'Explorateur de fichiers
-------------------------------------------
Aller dans ce dossier :
C:\Users\USER PC\Documents\propre à moi\lms-backend


ÉTAPE 2 : Clic droit sur "install-scheduler.bat"
-------------------------------------------------
➜ Clic droit sur le fichier "install-scheduler.bat"
➜ Choisir "Exécuter en tant qu'administrateur"
➜ Cliquer sur "Oui" si Windows demande confirmation


ÉTAPE 3 : Vérifier que ça fonctionne
-------------------------------------
Attendre 2 minutes, puis ouvrir un terminal (cmd ou PowerShell) :

cd "C:\Users\USER PC\Documents\propre à moi\lms-backend"
type storage\logs\scheduler.log

Vous devriez voir des logs d'exécution du scheduler.


═══════════════════════════════════════════════════════════════════════
   VÉRIFICATION MANUELLE (SI BESOIN)
═══════════════════════════════════════════════════════════════════════

OPTION 1 : Voir la tâche planifiée
-----------------------------------
1. Appuyer sur Windows + R
2. Taper : taskschd.msc
3. Appuyer sur Entrée
4. Chercher "Laravel_LMS_Scheduler" dans la liste
5. Vérifier que "État" = "Prêt"


OPTION 2 : Tester manuellement
-------------------------------
cd "C:\Users\USER PC\Documents\propre à moi\lms-backend"
php artisan schedule:run


═══════════════════════════════════════════════════════════════════════
   RÉSULTAT ATTENDU
═══════════════════════════════════════════════════════════════════════

Une fois installé, le système fera AUTOMATIQUEMENT :

✅ Fermer les séances 5 min après le départ de l'enseignant
✅ Détecter les participants déconnectés (sans heartbeat 5+ min)
✅ Synchroniser les séances depuis KLASSCI toutes les 5 min
✅ Finaliser les présences des séances terminées
✅ Nettoyer les données obsolètes

➜ PLUS BESOIN de cliquer sur "Terminer" manuellement !
➜ Les heures de présence seront CORRECTES automatiquement !


═══════════════════════════════════════════════════════════════════════
   EN CAS DE PROBLÈME
═══════════════════════════════════════════════════════════════════════

Si vous voyez "Accès refusé" :
-------------------------------
Vous devez exécuter install-scheduler.bat en tant qu'ADMINISTRATEUR.

Clic droit → "Exécuter en tant qu'administrateur"


Si ça ne fonctionne toujours pas :
-----------------------------------
Contacter le support technique avec :
- Le fichier storage\logs\scheduler.log
- Une capture d'écran de l'erreur
